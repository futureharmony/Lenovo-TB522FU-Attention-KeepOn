# Lenovo Legion Y900 (TB522FU) 注视不熄屏增强模块

为一个很简单的需求而生：**你正盯着屏幕看的时候，屏幕不要自己变暗熄灭。**

联想拯救者 Y900 的前置有一颗专门的"注视感知"小摄像头（不占用普通相机），硬件本身完全支持这个功能，系统设置里也有「注视时不熄屏」这个开关。但在移植版 ColorOS 上，**这个开关打开后并不起作用**——因为系统里缺少把它接通的那一段逻辑。本模块补上了这一段，让原装硬件真正替你看屏幕：

- 要熄屏的那几秒里，看一眼你是否还盯着屏幕 → **在看，就继续亮着**
- 你走开、扭头了 → 准时变暗熄屏，一秒不浪费

平时摄像头**完全断电**，只在需要判断的瞬间（不到半秒）短暂工作一下，几乎不增加耗电。

---

## 🆚 与同类方案对比

这台设备的 AON 相机曾有三种不同的软件方案，效果差别很大：

| | 联想原厂 | 底包自带的 LwKy（凝光） | 本模块 |
|---|---|---|---|
| 注视不熄屏能否用 | ❌ 功能没接通 | ⚠️ 有逻辑，但在本 ROM 上**容易引发崩溃和异常耗电** | ✅ 端到端接通，实测可用 |
| 稳定性 | 稳定（但功能没用上） | 差：可能导致芯片反复崩溃、一夜掉电严重 | 稳定：出问题自动断电，连续开机失败还会自动回退 |
| 耗电 | — | 较高（崩溃循环时） | 很低：整夜实测基本无感 |
| 开源可维护 | ❌ 闭源 | ❌ 不可控 | ✅ 全开源，附完整技术文档 |

> 补充说明：之前遇到过的整夜异常掉电，**大概率**是 LwKy 的一处配置缺陷导致相机芯片反复崩溃所致。本模块启动时会把这处配置修正掉，并带有崩溃自动断电等多重防护，连续多晚的整夜实测未再复现。不过耗电受信号、后台应用等多种因素影响，不排除个别场景仍有其他耗电来源。

## 🌟 核心特性

1. **让系统设置里的开关真正生效**：打开「注视时不熄屏」后，看屏幕续亮、离开准时息屏。
2. **几乎零耗电**：平时摄像头 100% 断电；只在快熄屏的瞬间探测一下，看完立刻关闭。
3. **多重保护**：硬件出异常自动断电隔离；服务意外退出自动拉起；连续 3 次开机失败自动禁用模块、还原全部设置，不会把设备变砖。
4. **手机上直接控制**：KernelSU 等管理器内置控制台（WebUI），开关、测试、调参数一屏搞定。
5. **日志默认关闭**：需要排查问题时在 WebUI 里手动打开，用完记得关，不占存储。

## 📦 安装

1. 设备已解锁 BL，并装有 KernelSU / APatch / Magisk 等管理器。
2. 从 [Releases](https://github.com/futureharmony/Lenovo-TB522FU-Attention-KeepOn/releases) 下载最新的 zip。
3. 管理器 → 模块 → 本地安装 → 重启即可。

装好后到 **设置 → 显示与亮度 → 注视时不熄屏** 打开开关，就能用了。

## 🖥️ 使用

### WebUI 控制台（推荐）

在管理器里点本模块的卡片即可打开：主开关、运行状态、一键测试、参数调节、日志。

- **一键测试**：点「测试」按钮立即做一次注视检测，几秒内告诉你"能不能看到你"。
- **日志记录**：默认关闭。排查问题时打开右上角开关（开启后界面会出现醒目提醒），用完请记得关闭。

### 命令行（root，可选）

```bash
attention_ctrl status       # 查看状态
attention_ctrl on|off       # 开 / 关
attention_ctrl test         # 单次注视检测
attention_ctrl bind         # 重新绑定系统服务（如果开关失效了可以试试）
attention_ctrl log [n]      # 查看日志
```

## 🛠️ 技术规格（一段话版）

本模块面向联想拯救者 Y900 (TB522FU，骁龙 8 Elite / ColorOS 16 移植版 / Android 16)，由四部分组成：一个调用前置 AON 低功耗相机（Camera 3 / OG0VE）的原生守护进程、一个无界面的后台服务 APK（通过 AOSP 标准的 AttentionService 契约接入系统电源管理，让系统在要熄屏前主动来"问"是否有人注视）、开机脚本与守护脚本（负责初始化、崩溃熔断、开机失败自动回退），以及 WebUI 控制台。感知推理跑在专用的 Hexagon DSP 上、不占用主处理器和普通相机；模块启动时会自动把可能导致芯片崩溃的相机配置（is_island）修正为安全值并在运行期持续盯防。配置存于 `/data/adb/tb522fu_attention/config.json`，日志默认关闭、有轮转上限兜底。只依赖系统标准接口和厂商固件，不绑定某一特定 ROM。
