🔧 高级 · AON 参数 （重启感知后生效）
❓ 各参数的用法与可用范围
evtMask · 事件位掩码（0–15）
控制 AON 引擎上报的事件类别，按位开关（各 bit 的官方定义未公开）。15（0xF）= 全部开启，是实测验证可用的组合；设 0 能开流但拿不到判定结果。推荐 15。
algo · 算法档位（1–2）
FD 引擎的算法选择。2 = FDPro，本机固件实测唯一验证可用的档位；1 为旧档位，未在当前固件验证。推荐 2。
width / height · 出图分辨率（160–640 / 120–480）
AON 相机每帧的宽与高。传感器原生模式是 480×360，偏离原生值可能拿不到事件帧。推荐 480×360。
dps · 检测帧率（1–30，单位：帧/秒）
每秒送出的检测帧数。越高注视判定越跟手、越耗电；越低越省电但反应变慢。传感器上限 30 fps。推荐 3（日常注视检测足够）。
改完点「应用参数」生效（会重启感知流，约 1 秒）。所有值均有合法范围校验，非法输入不会被应用。
